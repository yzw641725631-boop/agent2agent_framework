# Windows 桌面安装版与通知验收

> 2026-11-07。桌面版本 0.4.0，后端保持 0.3.1 / 数据库迁移 0006。本轮按用户要求暂缓项目组后续开发，完成桌面后台入口、凭证备忘、图标、托盘、推送和 EXE 安装包。

## 实际交付

| 用户要求 | 交付与使用方式 |
|---|---|
| PC 上方便打开网站后台 | 本机桌面已建立“Agent Hub 管理后台”快捷方式；应用顶部、侧栏和托盘均有后台入口。安装程序还会建立桌面及开始菜单的网站入口 |
| 管理员明文备忘 | 用户明确选择生成新密码并重置超管；原密码不可从哈希还原。新凭证已保存至项目根目录 `管理员凭证_明文.md`，加入 Git 忽略，限制本机文件访问；没有写入发行包或聊天输出 |
| 应用图标 | 内置 imagegen 生成深蓝/翡翠绿协作 A 图标，应用窗口、侧栏、托盘、EXE 和安装程序共用；导出 9 种尺寸的 Windows ICO |
| 托盘后台 | 默认关闭窗口后隐藏到托盘，保留 MCP 和事件连接；右键菜单可打开窗口、后台网站、项目动态或完全退出 |
| 推送 | 项目进度、重连后新增记录和权限变化通过现有 SSE 触发 Windows 通知；支持开关、摘要显示选项、点击打开动态和测试通知；首次加载历史与本设备重复事件不弹出 |
| EXE 安装 | `AgentHub-Setup-0.4.0.exe`，Windows x64 当前用户安装，创建应用及后台网站入口，支持卸载；同时保留签名 ZIP 自动更新渠道 |

密码重置已吊销旧超管会话和登记凭证，原有设备审批、邮箱设置及业务记录保留。使用凭证文件中的新密码重新登录即可；新设备仍需邮箱验证及超管审批。正式服务没有创建测试项目。

## 验证结果

- Node 桌面测试 32 项通过，包含推送关闭、摘要隐藏、旧配置默认值、首次历史静默、实时进度、同设备过滤、事件去重及断线补齐。
- 本机真实 Electron 窗口验证：新图标加载、后台按钮、设置持久化、四项桌面设置、关闭隐藏、窗口恢复均通过。
- Windows 原生通知出现 `show` 事件，确认系统通知已成功显示。应用退出后不接收实时推送；Windows 自身的免打扰/通知策略仍由系统控制。
- 真实 EXE 在工作区隔离目录安装成功；桌面与开始菜单入口完整，开始菜单快捷方式 `AppUserModelID=org.agenthub.desktop`。该身份与应用一致，符合 [Electron Windows 通知要求](https://github.com/electron/electron/blob/main/docs/tutorial/notifications.md)。
- 安装后启动独立测试配置，读取版本 0.4.0，实际打开/关闭 Windows 开机启动成功，测试通知已提交。托盘默认值为开启；关闭/恢复行为另由上述真实窗口测试验证。
- 隔离测试安装已卸载，临时卸载注册已移除，原有后台网站快捷方式已恢复；根目录凭证文件保留。用户可自行运行最终 EXE 安装。
- npm audit 无已知漏洞命中。新构建工具依赖的 minimatch 已固定至修复版本。构建依赖不进入运行包。
- 实际便携包 98 个文件检查未发现凭证备忘、服务器总册、`.env` 或发布私钥。安装程序使用同一份核验过的应用目录，构建后再次验证文件摘要没有变化。

实际 GUI 测试数据及截图保存在本机 `.local`；没有使用真实项目数据。隐藏窗口的截图/关闭 CDP 指令在测试时出现等待超时，改为仅通过该通道验证设置和版本，托盘寿命通过直接窗口测试验收。此限制不计作已通过的 CDP 关闭测试。
