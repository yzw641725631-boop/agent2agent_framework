# 通过 MCP 创建项目

> 2026-11-07。Windows 桌面端 0.5.0。复用当前服务器 0.3.2 的项目创建接口，未增加数据库迁移。

## 使用方式

1. PC 端在线升级到 0.5.0，使用超管账号登录。
2. 点击右上角“管理 MCP”，或“项目与 MCP → 管理 MCP 配置”。即使项目列表为空也能使用。
3. 复制管理 MCP 配置，加入 AI 开发工具的 MCP 设置并重新加载连接。
4. 对 Agent 说：“列出已有项目；如果没有 kms，就创建标识为 kms、名称为 kms 的项目。”
5. 项目创建成功后，PC 列表自动更新，可继续选择本地工程文件夹建立项目连接。

创建的是平台项目记录。当前文档源配置和工程目录绑定使用现有入口，项目组多仓库组装仍按原实施基线推进。

## 工具与授权

| 工具 | 参数 | 作用 |
|---|---|---|
| `hub_list_projects` | 无 | 列出当前超管的服务器项目 |
| `hub_create_project` | `slug`、`name`、`operation_id` | 创建平台项目，返回 ID、标识和名称 |
| `hub_check_version` | 无 | 已安装 PC 端提供版本检查与升级 |

`operation_id` 使用 UUID，同次请求重试保持不变，转为已有 REST API 的幂等键。实际创建继续由服务器 `POST /api/admin/projects` 校验超管身份并记录审计。

管理连接有自己的本机绑定 ID 和秘密，绑定登录账号与设备。每次列出或创建项目先通过平台会话重新读取 `/api/me` 验证超管角色，再调用实际业务接口；客户端缓存的角色不能代替服务端判断。普通项目连接不提供创建项目工具，其连接秘密不能用来执行管理请求。

退出登录会删除连接描述文件并停止访问；重新登录同账号可恢复。切换账号不能使用原账号的管理连接；“停用管理连接”会移除本地授权，使旧配置失效。更新期间管理写操作也会暂停，版本切换等待当前操作结束。请求已在服务器提交后，客户端停用不能撤回已完成的创建。

配置只含本机桥接命令和描述文件路径，服务器 Token 和设备私钥留在桌面端。该管理连接仅有项目列表和项目创建功能。

## 验证

- Windows 41 项桌面测试通过。新增覆盖首次项目创建、幂等重试、角色变化、退出、停用、账号切换、版本拦截、参数限制及真实 stdio 发现/调用。
- 指定服务器独立 `hub_test` 的 71 项后端测试通过。新增实际验证超管创建项目的同键重试不重复、同标识新操作冲突、普通成员创建被拒绝。测试库名强校验保持启用。
- 真实 Electron 界面与 stdio 桥接在隔离 Mock API 下完成：零项目时打开管理配置，通过配置启动桥接，发现工具并创建首个测试项目，PC 项目列表同步更新。该 GUI 测试没有连接正式库；真实 API 由上述 PostgreSQL 测试另行验证。
- 本轮没有在正式库预先创建 kms，也没有代用户粘贴 GitHub 凭证。正式服务接口及数据库版本保持不变。
