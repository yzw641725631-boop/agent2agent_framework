# 项目组仓库授权与 Git 交付

日期：2026-11-09。服务端 0.6.0 / 迁移 0009，桌面端 0.8.0。本批对应七点设计中的项目组、资源授权和代码接入主线；保留 0.7.0 的规则、日志、检查点和流程能力。发布状态在本文末尾记录。

## 用户现在怎样使用

**创建项目组 → 登记各端仓库 → 超管批准成员设备的仓库权限 → 绑定本机根目录 → 组装获准代码 → 在具体仓库开工 → 记录日志 → 推送任务分支 → 评审测试。**

框架与业务代码继续分仓库。一个项目组包含多个独立仓库，不要求把 Web、PC、API 放进一个能被全员拉取的大仓库。PC“组装仓库”和 MCP `hub_assemble_project` 使用同一实现，每个仓库有独立目录和固定 MCP 连接。详细步骤统一放在[使用指南](../使用指南.md)，Agent 的条件流程放在 [Skill 仓库参考](../skills/agent-hub/references/repositories.md)。

### 凭证与 Git 代理

服务器保存加密的仓库专用 PAT，或 GitHub App ID 与 RSA 私钥。App 换取安装令牌时指定一个登记仓库，并按操作缩小为 Contents read/write。该机制依据 [GitHub App 官方认证说明](https://docs.github.com/en/apps/creating-github-apps/authenticating-with-a-github-app/authenticating-as-a-github-app-installation)；实际 App 安装和真实私有业务仓库仍需超管配置。

成员取得的是不超过两分钟的平台 Git 票据，绑定会话、用户、设备、仓库及操作。写票据另绑定任务、运行、租约代次和日志提交号。票据只在子进程环境中提供给 Git，不写命令行、remote、工作文件、模型返回或持久存储；数据库保存票据哈希。

代理固定 GitHub 上游、拒绝重定向；每个 Git HTTP 请求复核身份和权限。receive-pack 命令段验证后才转发，禁止主分支、他人任务分支、删除、多分支更新及 push-options/push-cert。请求最大 64 MiB、响应最大 256 MiB，Nginx 有对应独立入口限制。规则发生变化后旧代码任务确认不能继续推送。

平台不能收回成员自己另外持有的 GitHub 凭证，也不能追溯删除其私自复制的代码。正在处理的已授权请求存在网络与执行时间窗口，不能声称远端操作可在任意瞬间被强行回滚。受限任务分支也不表示服务器已经独立审计 pack 内全部代码的业务合规性。

### 与旧数据兼容

项目初始为 `legacy`。首次登记仓库后单向切到 `scoped`，项目能力不隐式授予全部仓库。未归类历史任务、日志及文档继续保留，仅超管可见；Web 提供历史文档源。已有单源 HTTP 路径保留，新增仓库路径供多源读取。旧任务上下文哈希保留兼容，不因空的仓库字段强制失效。

迁移改变文档表的主键与来源外键，不应在已有多源数据后直接切回旧应用。生产发布先备份并验证备份目录；失败时保留证据，优先修复当前迁移与代码。如需回退数据，须先阻止写入并明确处理新产生的资料，不自动覆盖生产库。

- GitHub App 测试使用临时 RSA 密钥，验证私钥加密、不回显、权限拒绝、版本冲突、JWT 验签与指定仓库/读写权限缩小；不代表已配置实际 GitHub App。
- **真实 Chromium Web**：登记两仓库、凭证轮换、默认无仓库授权、逐仓库授权、绑定任务、切换同名文档源和历史源通过；浏览器控制台无错误。原有规则修订、人工任务全流程及代码任务 MCP 引导回归通过。
- **真实 Electron + 实际 Controller + 真实 Git**：根目录绑定、组装、生成仓库连接、配置不进入业务 Git、获取保留未完成修改、仓库撤权不影响项目组连接通过。
- Web/Electron 的界面测试使用隔离身份接口；真实身份、审批和 RLS 由服务器 PostgreSQL 测试覆盖。没有据此声称两台物理设备或七种工具全部验收。

源码编译与 Ruff 的 E/F/I/UP/B 检查通过（本轮排除 E501 长行规则，不能据此声称全量 Ruff 无例外通过）；桌面脚本语法、Skill 与包内文件白名单另做发布检查。既有 TestClient 的 httpx 弃用提示仍存在。

### Token 实测

[文本测量记录](审计数据/2026-11-09_080_Token测量.json)使用 `o200k_base` 与 `cl100k_base` 分词，仅用于比较公开文本，不是生产账单或节省比例。`o200k_base` 下，原 `install.md` 为 19,267 Token，入口 Skill 为 1,658；仓库、任务、工作记录参考分别为 1,070 / 1,412 / 1,068，按需读取。安装连接的 5 个工具描述为 612 Token，仓库开发连接的 25 个工具描述为 3,355 Token；这些成本与实际任务上下文还会叠加。

## 后续仍需实现

1. 服务器持久代码交付回执、未提交代码的受限快照上传、失败恢复和专用撤权收尾，再按部署清单卸载；失败不删唯一工作。

3. 独立 worktree、不同任务改同文件的协调、跨设备消息与职业角色派工。已有同任务租约不能代替跨任务冲突处理。
4. 宿主逐轮记录钩子、macOS 和七种工具逐一验收，以及恢复、容量、通知和完整框架退出演练。
