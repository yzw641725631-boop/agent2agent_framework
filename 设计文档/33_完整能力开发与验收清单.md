## 当前软件能力

| 用户目标 | 实现及边界 |
| --- | --- |
| 一句话安装、跨工具使用 | Windows统一入口安装桌面端、主Skill、审查Skill和MCP；支持七种宿主配置、旧配置合并及归属收据。自定义文件可显式指定；实际宿主加载仍须核验 |

| 远程MCP | 超管预注册固定账号、已批准设备、项目授权、仓库和回调，本人确认OAuth PKCE；短期访问、刷新轮换与撤权拦截。用于云端读取和进展通告，本机执行及卸载仍走桌面 |
| 账号恢复 | 邮箱找回与一次性恢复码；恢复码只显示一次、摘要入库、并发一次消费，恢复后旧会话与授权失效；不跳过设备及邮箱验证 |
| 原install制度与职业 | 原文保留，内置/自定义职业职责、standard/compact/strict流程、按任务加载；部署受管职责文档、脚本与测试；原始制度与任务范围不能由知识覆盖 |

| 多人及跨设备协作 | 任务依赖、范围冲突、独占认领、租约/过期接管、独立worktree；登记、派工和明确接收。桌面在线不等于Agent实际执行 |
| 逐轮日志与实时共享 | 代码修改轮次须有工作说明，桌面观察和原生钩子发现漏记；日志加密待传、服务端shared回执、SSE/重连补齐。断网pending不视为已经共享 |
| 代码与离职交接 | 日志、完整工作树备份、Git交付分别确认；可下载加密工作备份到新目录。撤权停止普通操作，限定上传后按收据移除整个已部署框架的归属文件；失败保留原工作 |

## 备份范围与实际边界

备份包括PostgreSQL身份权限、任务日志、资料原文、记忆和审核记录，已上传代码工作树，语义模型及恢复所需受控配置。Git保存源码历史。没有上传的本机改动不在服务器备份内；同机备份不覆盖整台原服务器丢失。restic密钥须另行保管。

Skill约定、服务器权限、宿主钩子、GitHub权限和操作系统能力各按实际范围生效。权限失效时停止普通工作，上传及按归属卸载分别核验；未确认的上传保持待处理，不删除原工作。明文凭证、模型/发布私钥及运行环境不进入源码和公开验收记录。严禁删除生产卷 `agent-hub-postgres-data`。
