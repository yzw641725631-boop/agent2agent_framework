| 主题 | 已验证的行为 |
|---|---|

| 邮箱设备 | 已验证邮箱账号的另一台新设备，也必须再次通过邮箱验证码和超管审批 |
| 管理员 | 不能无邮箱创建管理员；项目管理员不能创建管理员或项目、管理其他项目或批准授权 |
| 项目授权 | 管理员申请在批准前不提供项目访问能力；批准后只访问该项目及批准能力 |
| 跨项目读取 | 其他项目 ID 和随机未知 ID 均得到统一不可访问响应 |
| 设备证明 | 无证明、错误设备密钥、方法不符均拒绝；业务拒绝之后重用同一证明也被拒绝 |
| 会话刷新 | 保持原 grant 与绝对到期时间；轮换后旧访问凭证无效；旧刷新凭证再次使用会撤销整个家族 |
| 成员撤销与恢复 | 撤销后未过期访问令牌及刷新均失败；恢复成员关系也不恢复旧 grant，重新批准后才可访问 |
| 全局人员/设备状态 | 冻结、恢复账号不复活旧会话；撤销设备立即影响已有会话 |
| 审批完整性 | 数据库中申请内容被篡改后，原哈希审批被拒绝，不签发 grant |
| 幂等与并发 | 同键并发创建项目返回同一项目；同键变更内容拒绝；不同密码也能识别为不同请求 |
| 邮件验证码 | 发送冷却、失败次数持久化、五次失败锁定、单次消费生效 |
| 数据库隔离 | 无上下文不见项目；普通项目上下文只见本项目；连接池下一事务不继承前一身份 |
| 授权到期 | 访问令牌仍未过期时，grant 到期已阻止读取与刷新 |
| 数据库账号防误配 | API 拒绝使用表 owner 启动 |
